# Field-trial files for the hybrid-stress tutorial

These files ship with `hybrid_stress_correction.ipynb` so Colab does not depend
on an external GitHub mirror.

They are part of Ten Den et al. (2024) and are licensed **CC BY-NC-SA 4.0**.
See [`DATA_LICENSE.md`](../DATA_LICENSE.md).

| File | Contents |
|------|----------|
| `Plotspecific_processed.csv` | Plot-level potato observations (biomass, LAI, yield) |
| `Weatherfile_lelystad.xlsx` | Daily weather at Lelystad |
| `Weatherfile_vredepeel.xlsx` | Daily weather at Vredepeel |

Canonical deposit: Harvard Dataverse
[doi:10.7910/DVN/1LC6W7](https://doi.org/10.7910/DVN/1LC6W7).
